# AI検索・来店行動の計測

初回公開日を起点に、公開前、30日、60日、90日、その後毎月、`baseline.csv` と同じ列で6店を記録する。未取得値は空欄のままにし、0とは記載しない。

| 指標 | 取得元 | 記録単位 |
|---|---|---|
| Google AI検索の表示回数 | Search Console の生成AIパフォーマンス（利用可能な場合） | 店舗ページ別・月次 |
| Bing/Copilotの引用回数 | Bing Webmaster Tools の AI Performance（利用可能な場合） | 店舗ページ別・月次 |
| 地図経路、電話、Webクリック | Googleビジネスプロフィールのパフォーマンス | 店舗別・月次 |
| 予約・注文 | 各店で実際に使う予約・注文台帳 | 店舗別・月次。導線がない店は空欄 |

露出と来店・予約行動を同じ重みでレビューする。単純な合計スコアにはしない。両側の推移と、掲載情報の誤り・問い合わせの内容を合わせて判断する。Search ConsoleのAIレポートとBingのAI Performanceは対象面・集計方法が異なるため、数値を足し合わせない。

## 初回接続と確認

1. `www.m-i-m-o-s-a.com` の Search Console 所有権と、生成AIレポートの表示可否を確認する。ページ別の基準値を保存する。
2. 同じドメインを Bing Webmaster Tools で確認し、AI Performance が利用可能ならページ別引用数を保存する。
3. 管理権限を持つGoogleアカウントで4店のビジネスプロフィールを確認し、経路・電話・Webクリックを保存する。
4. プロフィールのWebリンクを新しい各店舗ページに更新し、予約や注文の導線が確定した店だけ、その件数を追加する。
5. 30・60・90日レビューでは、公開URLのインデックス状態、AI露出、地図行動、実際の予約・注文を同じ6店順に比較する。

サイト・ビジネスプロフィールの権限が未接続のため、このリポジトリ内では実測値を取得していない。`baseline.csv` の空欄は未取得を表す。
